## The inheritance rule

One rule, resolved in exactly one place (`lib/format/effective.ts`):

```
effective value = explicit override, else project default
```

`null` means inherit and is the default state of every override attribute.
A stored value — **including `0`** — means the author deliberately overrode the
default. Editor rendering, DOCX export and (later) published HTML all resolve
through this module.

### Thai (complex script)

Read from Word for the Thai paragraphs:

```
Name='Sarabun'  NameAscii='Sarabun'  NameFarEast='Sarabun'  NameOther(cs)='Sarabun'
Size=16  SizeBi=16
```

`NameOther` is Word's complex-script slot (`w:cs`) and `SizeBi` its
complex-script size. Both resolve to Sarabun 16pt, so Thai does **not** fall
back to Word's default complex-script font (Cordia New). Visually confirmed on
screen: `ทดสอบวรรณยุกต์ไทย: ก่ ก้ ก๊ ก๋ กิ๊ กี้ ปั๊ก เปี๊ยก โป๊ะ แน่ะ ไหม้ ญี่ปุ่น` renders with
tone marks correctly stacked and no clipping, including at double line spacing.

### Known fidelity notes (Word)

1. **Line spacing reads as 1.079, not 1.08.** OOXML expresses "Multiple" spacing
   in 240ths of a line, so 1.08 → `Math.round(240 × 1.08)` = **259**, and
   259 / 240 = 1.0792. Word's dialog displays this as **1.08**; the object model
   reports the exact 1.079. This is inherent to the OOXML unit and is the
   mapping specified in the architecture plan — not a defect, but it does mean
   1.08 cannot be represented exactly.
2. **A page break creates one extra empty paragraph.** `pageBreak` becomes a
   paragraph whose only content is the break. Word shows an empty paragraph mark
   at the top of the new page. Harmless, but visible with formatting marks on.

### Inheritance regression (the required case)

Project default 1.08 → 1.15, with paragraph A inheriting and paragraph B
overridden to 1.5:

- A moves 1.08 → 1.15
- B stays at 1.5

Verified at the resolver level **and** end to end through generated OOXML
(`w:line` values move from 259 to 276 for A, while B stays at 360, and no
paragraph remains pinned at 259). The same test exists for font family, font
size, first-line indent, paragraph spacing and alignment.
